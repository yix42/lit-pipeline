# Folio · 文献工作台

一个**纯本地**的文献工作台。名字取自「对开本」——把一页纸摊开成两面：左边是你的阅读卡，右边是原文。

支持卡片与原文双向锚定定位，支持 PDF → Markdown。无需联网、无需安装，双击即用。

> 还能让 WorkBuddy 里的 AI 直接读写这些文献和卡片，见 [README-MCP.md](README-MCP.md)。

---

## 一、怎么打开

**双击 `app.html`** 即可（用 Chrome / Edge 打开）。

想让 WorkBuddy 里的 AI 也能读写这些数据时，双击 `start-server.bat` 保持服务运行，然后访问 http://127.0.0.1:8787/。

必须保持以下文件结构，不要单独把 `app.html` 拷走：

```
文献工作台/
├── app.html          ← 双击这个
├── js/
│   └── app.js
├── vendor/
│   ├── pdf.min.js
│   └── pdf.worker.min.js
├── server/           ← 给 WorkBuddy 连接器用的本地服务
├── data/             ← 数据文件（首次运行自动生成）
└── start-server.bat  ← 想让 AI 也能读写时双击这个
```

> `vendor/` 里是本地化的 pdf.js 引擎（3.11.174），**不联网也能解析 PDF**。
> 若把 `app.html` 单独拷走，PDF 导入功能会失效。

## 二、四个模块

| 模块 | 位置 | 做什么 |
|---|---|---|
| **文献库** | 顶部下拉 | 导入 / 切换 / 导出全部文献 |
| **阅读卡** | 左栏 | 7 种卡片类型，可自由写笔记、批注、打星标 |
| **原文对照** | 右栏 | 双栏并列阅读，卡片与原文双向锚定 |
| **今天要处理** | 顶部置顶 | 逾期（标红）/ 今日 / 临近到期，一键处理 |

右上角还有一个**同步状态灯**：绿色=已连本地服务（AI 可读写），蓝色闪=同步中，灰色虚线=离线模式可点击启用。

### 7 种卡片类型

| 代号 | 名称 | 用途 |
|---|---|---|
| KT | 知识主题 | 这篇文献讲的核心问题 |
| KC | 核心概念 | 关键术语、缩写、定义 |
| KM | 方法要点 | 设计与流程中值得复用的部分 |
| KR | 关键结果 | 主要发现与数据 |
| KV | 证据数据 | 具体数值、统计量、效应量 |
| KS | 可证伪问题 | 值得后续验证的开放问题 |
| NT | 随手批注 | 临时想法，不分类 |

## 三、四条导入通道

点顶部「导入」，四个通道：

### 1. PDF 文件 → 自动转 Markdown

选一个 PDF → 自动解析为结构化 Markdown，直接进右栏原文视图。

**已处理的排版难点：**

- **双栏识别**：按 x 起点空白走廊判定栏边界，在聚行**之前**分栏
  （双栏 PDF 左右同行 y 几乎相同，先聚行会把两栏混成一行）
- **阅读顺序**：左栏整栏读完，再读右栏 —— 不是左右交替
- **跨栏断句缝合**：跨栏时被切断的同一句话会自动接回
  （仅在栏/页边界缝合，且要求前段未以标点收尾，避免误合并相邻段落）
- **标题层级**：按字号相对正文自动分 `# / ## / ###` 三级
- **参考文献**：`[1] [2] …` 格式条目识别为 ref 类型
- **页码注释**：每段带 `<!-- page N -->` 标记
- **降噪**：页眉、页脚、纯页码行自动剔除

导出 Markdown：右栏切到 **vText / vSrc** 视图 → 点「复制 MD」或「下载」。

### 2. Zotero 导出（RIS / BibTeX）

Zotero → 右键文献 →「导出文献」→ 选 **RIS** 或 **BibTeX** → 复制文本粘贴进来。
自动解析标题、作者、DOI、年份、期刊。

### 3. AI 阅读卡（JSON）

让 AI 帮你生成阅读卡，粘进来看。格式：

```json
{
  "paper": "文献标题（可选，指定归属；不填则归到当前文献）",
  "cards": [
    {
      "type": "KR",
      "quote": "原文中的某一句话（用于自动定位到原文）",
      "note": "你的批注"
    },
    {
      "type": "KV",
      "quote": "另一句原文",
      "note": "AUC 0.71，中等判别力"
    }
  ]
}
```

**关键**：`quote` 填**原文里真实存在的句子**，导入后会自动在右栏定位并高亮。
这句原文最好在 30–200 字符之间，太短可能定位不准。

### 4. JSON 备份恢复

导出全量数据为 JSON 文件；换电脑或换浏览器时导入恢复。

## 四、双向锚定定位

这是本工作台的核心。

### 卡片 → 原文

点左栏任意卡片 → 右栏自动滚动到对应位置，该句**黄色高亮 + 描边激活**，左栏卡片同步高亮。
锚点记录为 `{段落索引, 段内起始, 段内结束}`，PDF 重新解析后仍可复用。

### 原文 → 卡片

在右栏**选中一段文字** → 浮出「存为阅读卡」按钮 → 点它 → 自动新建卡片并建立反向锚点。

## 五、数据安全（含 AI 连接器）

数据存在浏览器 **localStorage**，关闭页面不丢。

⚠️ **localStorage 上限约 5MB**。文献卡积累多了可能写不进去。

**建议：**

- 每积累一批文献，点顶部「备份」→ 导出 JSON
- 换设备 / 换浏览器 / 清理浏览器数据前，务必先导出
- PDF 原文件**不存进 localStorage**（体积太大），只存解析后的文本；重开时需要重新导入 PDF 或用备份恢复

「清空」按钮会二次确认。首次打开会载入示例数据方便你看效果，清空后不会复活。

## 六、自测脚本（开发者）

```bash
node tools/selfcheck.js     # 静态自检：架构/响应式/备份/日期/PDF 管线
node tools/pdftest.js       # PDF 端到端：22 项
node tools/runtest.js       # 浏览器交互：36 项（需 puppeteer-core + 本机 Chrome）
python tools/make_sample_pdf.py testdata/sample.pdf   # 生成双栏测试 PDF
```

修改 `js/app.js` 后请至少跑 `selfcheck` + `pdftest`。
